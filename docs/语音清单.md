# 语音清单 — 播报 WAV

物理文件放 `02-github/watchdog/sounds/`，部署时由 `deploy/deploy.sh` 同步到板端
`/etc/watchdog/sounds/`。生成方式见 [`03-语音合成流水线.md`](03-语音合成流水线.md)，
生成脚本 `tools/gen_voices.py`。

## 格式要求（务必一致）

| 项 | 值 |
|---|---|
| 容器 | WAV（PCM） |
| 采样率 | **44100 Hz** |
| 声道 | **双声道（stereo）** |
| 位深 | **16-bit** |
| 峰值 | 约 89% FS（脚本自动归一化） |

> **必须是双声道 44.1kHz**：ES8323/I2S 硬件要求双声道 frame slot，单声道会被按
> 双声道 slot 消耗 → 约 1.9 倍速、音调尖细（根因见 `docs/01-声音尖细根因.MD`）。
> 文件名逐字一致（含中文与全角逗号）。

## 三、PhaseWatcher 播放规则

- 触发源：按键播报只在 `last_source=gpio` 时播放；屏幕按钮由 device-ui 给视觉反馈，不重复播。
- 去重：按键按 `last_event_id`；`zero_done_speaking` / `calibration_complete` 按
  `phase_version`；同一次只播一次。
- 握手：`标0完成，请穿戴设备，录制准备动作.wav` 播放结束（含 played / preempted /
  skipped / 缺 WAV / 告警超时）后，watchdog 必须向 `/tmp/unified_capture.sock` 发送
  `announce_done:ui:watchdog-<epoch_ms>-<counter>`；同版本只发一次，失败按同一
  event_id 重试。
- 优先级：关机 > 告警 > 按键反馈 > 流程语音。告警中按键反馈跳过；流程语音最多等 10s。
- 抢占：新按键可打断在播的旧按键/流程语音；流程语音被打断后仍完成握手。
- `busy` 预留：`设备正在收尾，请稍后.wav` 因后端不写 `phase_status.last_*`，
  当前不会触发。
- 实现与测试见 `.specrune/spec/watchdog/backend/phase-watcher.md`。
