# 语音清单 — 播报 WAV

物理文件放 `02-github/watchdog/sounds/`，部署时由 `deploy/deploy.sh` 同步到板端
`/etc/watchdog/sounds/`。生成方式见 [`03-语音合成流水线.md`](03-语音合成流水线.md)，
生成脚本 `tools/gen_voices.py`。

## 格式要求（务必一致）

| 项 | 值 |
|---|---|
| 容器 | WAV（PCM） |
| 采样率 | **44100 Hz** |
| 声道 | **双声道（stereo）** |
| 位深 | **16-bit** |
| 峰值 | 约 89% FS（脚本自动归一化） |

> **必须是双声道 44.1kHz**：ES8323/I2S 硬件要求双声道 frame slot，单声道会被按
> 双声道 slot 消耗 → 约 1.9 倍速、音调尖细（根因见 `docs/01-声音尖细根因.MD`）。
> 文件名逐字一致（含中文与全角逗号）。

## 备注

- 六目（jhh02 + jhh04）合并成一个播报项，与 watchdog 的 `sixcam` 一致。
- 屏幕检查默认 `not_configured`（未启用），所以 `屏幕故障.wav` 只在启用屏幕门禁后才可能播。
- 全部语音由 `tools/gen_voices.py` 用 `zh-CN-XiaoyiNeural` 统一合成，替换了早期人工录音与占位正弦音。
- 板端试听：`bash deploy/play_sounds.sh`。
