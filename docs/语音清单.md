# 语音清单 — 开机自检播报

device-ui 开机自检播报（`server.cjs` 的 `ANNOUNCE_SOUNDS`）需要的语音文件。物理文件放 `02-github/watchdog/sounds/`，部署时同步到板端 `/etc/watchdog/sounds/`。

## 格式要求（务必一致）

| 项 | 值 |
|---|---|
| 容器 | WAV（PCM） |
| 采样率 | **24000 Hz**（44.1kHz 也实测可播） |
| 声道 | **单声道（mono）** |
| 位深 | **16-bit** |

> 板端 `aplay -q` 走 `pcm.!default`（`type hw`，不重采样）。**文件名逐字一致（含中文）**。

## ⚠️ 缺失

- **`start-ok.wav`（开机成功）已被删除**——device-ui 播「开机成功」会因找不到文件而静默退化，需重新提供/录制这个文件。

## 备注

- watchdog 自己的 USB 告警用另一套（`六目断开.wav`/`六目恢复.wav`，六目合并通道），与 device-ui 的「双目侧/四目侧」拆分是两套，别混淆。
- 录制完替换 `sounds/` 下同名 TTS 占位文件即可，代码引用文件名、不用改代码。
