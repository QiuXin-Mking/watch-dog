# 语音清单 — 开机自检播报

device-ui 开机自检播报（`server.cjs` 的 `ANNOUNCE_SOUNDS`）需要的语音文件。物理文件放 `02-github/watchdog/sounds/`，部署时同步到板端 `/etc/watchdog/sounds/`。

## 格式要求（务必一致）

| 项 | 值 |
|---|---|
| 容器 | WAV（PCM） |
| 采样率 | **44100 Hz** |
| 声道 | **双声道（stereo）** |
| 位深 | **16-bit** |

> **必须是双声道 44.1kHz**：ES8323/I2S 硬件要求双声道 frame slot，单声道会被按双声道 slot 消耗 → 约 1.9 倍速、音调尖细（根因见 `docs/01-声音尖细根因.MD`）。文件名逐字一致（含中文）。
