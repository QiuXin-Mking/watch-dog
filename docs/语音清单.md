# 语音清单 — 开机自检播报

device-ui 开机自检播报（`server.cjs` 的 `ANNOUNCE_SOUNDS`）需要的语音文件。物理文件放 `02-github/watchdog/sounds/`，部署时同步到板端 `/etc/watchdog/sounds/`。

## 格式要求（务必一致）

| 项 | 值 |
|---|---|
| 容器 | WAV（PCM） |
| 采样率 | **24000 Hz** |
| 声道 | **单声道（mono）** |
| 位深 | **16-bit** |

> 板端 `aplay -q` 走 `pcm.!default`（`type hw`，不重采样）。文件名逐字一致（含中文）。

## 备注

- 六目（jhh02 + jhh04）合并成一个播报项，与 watchdog 的 `sixcam` 一致，用 `六目断开.wav`/`六目恢复.wav`。
- 屏幕检查默认 `not_configured`（未启用），所以 `屏幕故障.wav` 只在启用屏幕门禁后才可能播。
