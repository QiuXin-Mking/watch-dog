# 语音清单 — 开机自检播报

device-ui 开机自检播报（`server.cjs` 的 `ANNOUNCE_SOUNDS`）需要的语音文件。物理文件放 `02-github/watchdog/sounds/`，部署时同步到板端 `/etc/watchdog/sounds/`。

## 格式要求（务必一致）

| 项 | 值 |
|---|---|
| 容器 | WAV（PCM） |
| 采样率 | **24000 Hz**（44.1kHz 也实测可播） |
| 声道 | **单声道（mono）** |
| 位深 | **16-bit** |

> 板端 `aplay -q` 走 `pcm.!default`（`type hw`，不重采样）。文件名逐字一致（含中文）。
