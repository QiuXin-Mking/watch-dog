# 语音清单 — 开机自检播报

device-ui 开机自检播报（`server.cjs` 的 `ANNOUNCE_SOUNDS`）需要的语音文件。物理文件放 `02-github/watchdog/sounds/`，部署时同步到板端 `/etc/watchdog/sounds/`。

## 格式要求（务必一致）

| 项 | 值 |
|---|---|
| 容器 | WAV（PCM） |
| 采样率 | **24000 Hz** |
| 声道 | **单声道（mono）** |
| 位深 | **16-bit** |

> 与 `start-ok.wav` 完全一致。板端 `aplay -q` 走 `pcm.!default`（`type hw`），**24kHz mono 与 44.1kHz 立体声均已实测可播**（现有腕部语音即 44.1kHz 立体声）。但建议新录音统一 **24kHz mono**，与 `start-ok.wav` 保持一致。**文件名必须逐字一致（含中文）**。
